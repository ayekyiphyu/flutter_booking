# YoyakuApp

A sample **Flutter** project for managing reservations (予約). This app serves as a starting point for learning or developing a booking or scheduling app using Flutter.

---

##  Getting Started

These instructions will help you set up and run the project locally.

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (Stable Channel)
- Dart SDK (comes with Flutter)
- IDE like [VS Code](https://code.visualstudio.com/) or [Android Studio](https://developer.android.com/studio)
- An Android or iOS device/emulator
